# E2 学习率、更新预算与函数改变量

在 MATR 已登记的三个源域工况折上，固定 seed 42、draw 0、K=1/3/5，共比较 **72 条训练轨迹、216 个检查点、108 组配对**。每条轨迹连续训练 60 步，在第 10、30、60 步评价。Bridge、Decoder 和参考权重冻结，ABBA 与 LoRA 各有 **73,728** 个可训练参数。

每折按固定哈希顺序取参考模型 fit 集的 8 颗电芯，只用早期前缀。在 101–5000 圈固定网格计算模型输出相对共同冻结参考的 RMS 改变量 R。等幅诊断取两臂 R 的较小值，以 f₀ + ρ(f−f₀) 收缩原始输出。对照在输出层进行，沿用已训练的权重。源 Query 标签只用于打分，**目标未来标签读取数为 0**。

## 可支持的判断

- ABBA_R4X4 从 1e-4 减到 3e-5，30 步 Query MAE 平均变化 -6.75203e-06，4/9 改善。采样 Support MSE 平均变化 +1.13229e-05，0/9 改善。源锚 R 均值从 0.002369842 变为 0.0005499317。
- LORA_R8 从 1e-4 减到 3e-5，30 步 Query MAE 平均变化 -0.00050928，5/9 改善。采样 Support MSE 平均变化 +0.000107586，1/9 改善。源锚 R 均值从 0.07159423 变为 0.06075915。
- 3e-05 等幅前后 ABBA 减 LoRA 的均值为 -0.00200024 和 -4.52478e-07，符号保持。配对的等幅后绝对差均值是 1.881162e-06。
- 1e-04 等幅前后 ABBA 减 LoRA 的均值为 -0.00250277 和 -3.96409e-06，符号保持。配对的等幅后绝对差均值是 2.10331e-05。
- 两档均出现时距反例。原始 ABBA 在 101–500 圈 MAE 较低，在 501–5000 圈的两个分窗 MAE 较高。1001–5000 圈仅有 12 个折/K 电芯实例，等幅后的差异应连同分母读取。
- 零步数值噪声 RMS 最大 0。0 个训练后检查点 R 等于零，0 个检查点 R 未超出初始数值噪声或 1e-12 计算阈值。108/108 组有非零可解析共同半径。
- 优势是固定电芯、训练数据和参考后可重算有符号的幅度对照。局限是每折只选择一个支持抽样，采用既往已用的源折。等幅方向比较发生在两臂较小的函数半径，较大半径上的方向优劣仍需相应数据。

完整指标和配对见 `SCALE_CURVES.csv`、`MATCHED_FUNCTION_SCALE.csv`。分窗逐组 MAE、MSE 和分母见 `SELECTED_WINDOW_DIAGNOSTIC.csv`。
