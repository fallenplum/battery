# 保持奇异谱的条件旋转在 MATR 源域的筛选

**停止判定为 `STOP_SIMPLE_BASELINE`。** 真实形变旋转优于常数角、旧静态核心及固定联合空间。完整轨迹 MAE 同时高于 K0、CAL2、小步 LoRA 和同形变 GAIN。真实条件与独立训练置乱的方向差异在参数等幅后只在一折有利，未通过筛选。

## 数据与执行

用同一冻结 Moirai 参考、Bridge 和 Head，使用 MATR 三个源协议折、种子 42、K3。三个折各有 20 颗外层 Query、3 个 Support 组合。60 颗 Query 和 39 个协议在外层跨折去重。评分只使用各电芯第 101–5000 圈的有效观测。保持各折原来的参考拟合角色，条件映射仅在本折拟合集的 32 个训练 episode 学习。每个 episode 从零初始化 C，使用三步可微的真实非线性 Support SGD，并在 3 颗不同协议的训练 Query 上反传。三个 fold 的开发全部冻结后开始按各折外层角色评分。三个选参折实际各有 3、1、3 个 Support 组合，产出 259 个评分格。外层划分在既往研究中使用过，一颗电芯可在另一折作为训练或验证电芯。

形变输入来自前 100 圈的 54 维有符号电学描述，使用 2.8–3.1 V 共同实测电压范围。115 颗源电芯的 6,210 个特征值均有效。基底最大正交误差为 2.35×10⁻⁸，真实 Moirai 原始参考与合并参考的零步输出最大差为 5.96×10⁻⁷。目标未来标签读取为 0。

真实形变旋转相对 K0 的完整窗 MAE 高 0.001850865，三折同向。相对 CAL2 高 0.000637805，两折低于 CAL2，另一折差距为 +0.004263794。相对同特征 GAIN 高 0.000882951。相对小步 LoRA 高 0.001809684，三折同向。小步 LoRA 的折内锁定为 1e-5×10、1e-6×1、1e-5×10。CAL2 三折均选 Support-Gram ridge 倍数 1e-4、η=0.1。七种核心臂在三折均在学习率 0.1 的搜索下边界取最好值，低于 0.1 的学习率没有在本轮训练。

## 条件和尺度的贡献

差值为真实形变减参照的完整窗 MAE，负值有利。参数等幅取两臂较低的源锚更新 Frobenius RMS，缩放核心后重新跑真实模型。输出等扰动将实际预测沿各自输出修正方向缩放，使两个预测在无标签源锚上的 RMS 相同。后者的结果对应所用的较小半径。

| 参照 | 原始 ΔMAE / 有利折 | 参数等幅 ΔMAE / 有利折 | 输出等扰动 ΔMAE / 有利折 |
| --- | --- | --- | --- |
| 常数角 | −0.000245875 / 3 | −0.000284470 / 3 | −0.000139667 / 3 |
| 独立训练置乱 | −0.000107350 / 1 | −0.000119603 / 1 | −0.000112677 / 2 |
| 同核心 Query 置乱 | −0.000085330 / 2 | 同 C 逐层保持奇异谱 | −0.000110878 / 2 |
| 小步 LoRA-r8 | +0.001809684 / 0 | 不适用 | +0.000005495 / 0 |

真实条件角并非零更新。9 个实际任务的源锚预测 RMS 为 0.031178–0.116003，平均约为小步 LoRA 的 12.6 倍。将其输出缩放至与 LoRA 相同的源锚位移后，完整窗 MAE 差距缩小，三个折仍全部为正。固定同组 C 的置乱保持了实际 Support 预测逐值相同。两种 Query 形变输入下角度和实际预测可以变化，参数矩阵每层的奇异谱不变。独立训练置乱在参数等幅时只一折有利，与同核心反事实的弱平均收益需要一起解释。

## 误差随时距的方向

| 窗口 | 物理 Query 电芯 | K0 MAE | 真实形变旋转 MAE | 常数角 MAE |
| --- | ---: | ---: | ---: | ---: |
| 101–200 | 60 | 0.003702 | 0.004964 | 0.005040 |
| 201–500 | 59 | 0.015216 | 0.017868 | 0.018132 |
| 501–1000 | 54 | 0.070297 | 0.064023 | 0.064055 |
| 1001–5000 | 14 | 0.113781 | 0.107584 | 0.107465 |

真实形变旋转的采样 Support MSE 从 0.00141949 降到 0.00118559，9 个任务均下降。用真实预测做 MSE 分解，9 个任务的 Query 交叉项均为负。折 1 的三个任务全步过冲，其余六个任务 Query MSE 改善。最大分解残差为 8.24×10⁻¹⁸。完整窗 MAE 与 MSE 的方向存在差异。501 圈以后候选相对 K0 的分窗 MAE 降低，常数角在同两个窗也有相近改善。最远窗只有 14 颗有有效观测的电芯。

## 成本与判定边界

同一块 RTX 4060 上，全部五臂×三折共 480 次源映射更新、1,440 次可微 Support 更新，映射训练合计 194.3 秒。全部源开发三折的墙钟合计 258.1 秒，外层三折评分循环合计 45.0 秒。完整网格前向计时包括一次 episode 的 31 颗 Support、Query 和源锚电芯，耗时包含批处理与输出拷贝。映射是按电芯条件化的，冻结的基底可共享。固定联合对照用 8×2 核心在预算匹配时牺牲右子空间宽度和矩阵秩。

已核对的结论适用于当前参考、基底、特征、优化网格和历史源协议。优势是同核心换条件可以严格锁住参数奇异谱。外层复用历史数据、核心步长落在边界、远期覆盖有限，均限制机制和跨域外推。依照预定门槛，本候选停在 K3 源域筛选。

25 项回归通过。独立重放核验 15 个冻结映射与 9 个真实预测包的哈希，逐电芯复算 9,900 条分窗记录、405 组原尺度对照和 675 组两种等幅对照，并再现同一停止判定。验证只读取已锁定的 60 颗源 Query 未来观测。
