# 真实输出修正的方向、幅度与跨电芯迁移

三个实验均已完成。MATR 上，ABBA 的多数完整轨迹负迁移由不利的实际输出修正方向解释。HUST 的 LoRA-r8 同时出现不利方向和幅度过大。源内将两方法的输出修正缩放到相同的锚点扰动后，原始 MAE 差距大幅收窄。从前 100 圈提取的相似性在留出协议的完整轨迹方向预测上未超过训练组先验。

## 实验一 真实输出的 MSE 分解

对保存的非线性预测取 e=f₀−y、d=fadapt−f₀。逐电芯在真实观测点上计算交叉矩和修正能量，再对电芯等权。直接验证了 MSE(f₀+ηd)−MSE(f₀)=2η〈e,d〉+η²〈d,d〉。η=1 使用实际适配输出。目标 Query 有 64,155 条电芯分窗记录，其中 1,365 条保留为无观测。可评分记录的 MAE 与原值逐行一致，目标 Query 的最大恒等式残差为 5.55×10⁻¹⁷。

先重建源内 ABBA 和 LoRA-r8 的 56 个适配任务输出，再读取目标后缀。源快照恢复执行 1,680 次优化。沿用父实验 K3/K5 的 12 个源任务，Query MAE 重放最大误差为 1.57×10⁻⁸。目标 Query 复用 546 个保存的预测槽，目标 Support 复用 504 个已有状态重放 540 个非零槽，新增目标优化为 0。独立 FP64 复算的采样 Support MSE 与原记录最大差为 2.33×10⁻⁸。

| MATR ABBA | 1 | 9 | 6 | 0 |
| MATR ABBA | 3 | 15 | 11 | 0 |

MATR ABBA 的完整轨迹负迁移主要与当前输出方向不利相符，沿同方向正向缩小最多返回 K0。HUST LoRA 的两种失败形态同时存在。源域的 LoRA-r8 1-shot 同样观察到 4/22 个方向不利与 4/22 个全步过大。每行基于相同 Support 集合与固定 Query 分布，重复 seed/draw 是重复评价轴。

ABBA 整体修正较小。目标 K5 完整窗的修正 RMS，MATR 为 0.000568、HUST 为 0.001414。LoRA-r8 对应 0.015323、0.038262，约为 ABBA 的 27 倍。MATR ABBA 的 K5 MAE 上升 0.000070，远期 MAE 下降 0.000131，远期 MSE 的平均方向仍为恶化。HUST LoRA K5 的完整 MAE 下降约 0.001993，同时完整 MSE 上升约 0.000011。两种误差指标均保留。

整个目标矩阵的 504 个去重非零状态在完整窗均保持采样 Support 和完整 Support 的交叉项及 MSE 变化同符号。分窗出现两例交叉项符号变化与两例 MSE 变化符号变化。MATR 的 ABBA K5 在 90/120 条重复电芯记录上出现不同时距的交叉项异号，同一 episode 的不同电芯也并存有利和不利方向。逐电芯、时距、K 的事实与 oracle η 保存在 E1 表中。oracle 仅使用已知结果诊断这条方向的可用幅度。

## 实验二 优化尺度与更新秩

用同一冻结源参考、Bridge、Head、12 个 Q/V 位置、每折每 K 的 Support draw0 和采样 MSE。ABBA(4,4) 与 LoRA-r8 各训练 73,728 个参数。在原三个源工况折和种子 42，以 1e-5、3e-5、1e-4、1e-3 各训练 60 步，评分 10、30、60 步。72 条正式轨迹产出 216 个检查点、108 个同扰动配对，合计 4,320 步。本机 RTX 4060 实际优化累计 291 秒，PyTorch 峰值分配 264.0 MiB，峰值保留 322 MiB。旧网格重合的 36 个检查点与原 Query MAE 最大相差 2.35×10⁻⁸。读取的目标标签为 0。

| 30 步学习率 | ABBA / LoRA 平均源锚 RMS | 原始 ABBA − LoRA MAE | 等扰动 ABBA − LoRA MAE | 原始 / 等扰动 ABBA 占优 |
| --- | --- | ---: | ---: | --- |
| 1e-4 | 0.002370 / 0.071594 | −0.002503 | −3.96×10⁻⁶ | 8/9 / 6/9 |
| 3e-5 | 0.000550 / 0.060759 | −0.002000 | −4.52×10⁻⁷ | 8/9 / 6/9 |

源锚在每折参考模型的拟合集取固定的 8 颗电芯，以前缀为输入，在 101–5000 圈固定网格计算 RMS。两方法分别将已生成的输出朝共同 f₀ 收缩至各配对中较小的 RMS。锚的未来标签未用于确定缩放。108 对均超过数值噪声。以上两档学习率下，ABBA 的完整 Query MAE 相对于 f₀ 的均值分别增加 7.08×10⁻⁶、3.24×10⁻⁷。全矩阵的 216 个检查点均降低采样 Support MSE。原设置下，LoRA-r8 平均降低 Query MSE 的幅度较大，同时其完整 MAE 上升 0.002510。等扰动方向比较只在两个输出较小的锚点半径成立。

在原 1e-4、30 步设置，ABBA / LoRA-r8 的平均更新 Frobenius 范数为 0.003745 / 0.166869，平均层 99% 能量秩为 14.79 / 7.07，最高数值秩为 16 / 8。两方法的秩差与明显不同的函数位移同时存在。有限网格的 LoRA-r8 三个 K 均在 1e-5、10 步取得各自最低三折平均 MAE。ABBA 的 K1 也落在该边界，K3 和 K5 分别落在 1e-4 的 10 和 30 步。最低值来自已用源折上的诊断性筛选，后续目标协议未采用这些设置。

## 实验三 源协议组留出

用 E1 的 44 个单 Support 适配状态产生两方法的配对输出。评价覆盖 14 个不同 Query 协议、22 颗物理 Query 和 1,436 个有观测的配对分窗记录。每个冻结源折内按 Query 协议留一，拟合时移除同协议 Support 和重合的 Query 电芯。协议仅用于分层和划分，输入来自前 100 圈。Brier 先在协议组内平均，再按组平均，越低越好。

| ABBA 的初始有利方向 | 0.146770 | 0.171133 | 0.179105 | 0.191629 |
| ABBA 的全步 MSE 改善 | 0.151592 | 0.172847 | 0.198445 | 0.202795 |

| LoRA 的全步 MSE 改善 | 0.204425 | 0.224845 | 0.242283 | 0.237943 |

完整窗中，所有相似性版本的 Brier 均高于先验。LoRA 在 501–1000 圈有待复核的信号，单用表征距离使全步收益预测的 Brier 降低 0.032130，三个源折中两个同向。1001 圈以后仅有一个折的两颗电芯可以完成留出评分。部分电压范围描述因预处理使用共同网格而恒定，电流与电压形态均只能从已有 VIQ 网格提取。当前结果约束这一组观测描述和距离能提供的证据。

## 证据边界

方向与过冲的区分对保存的输出和观测掩码具有高置信度，MAE 单独解释。E2 在三个既有源折显示原始 MAE 差与位移尺度强相关，关于高秩或方向带来跨域优势的证据有限。E3 支持当前可观测特征和距离在这组协议上的完整窗阴性结论，对新协议和远期泛化的置信度较低。目标 Query 属于已暴露队列，本轮仅用于回顾性打分与诊断 oracle，新增目标优化为 0。
