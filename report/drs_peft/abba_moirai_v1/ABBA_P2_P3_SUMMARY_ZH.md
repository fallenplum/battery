## 评估范围

本轮已验证 546/546 个目标评分槽，状态 **COMPLETE**。MATR 和 HUST 分别采用固定的 8 颗和 39 颗 Query，每次仅使用全域总 K=0、1、3、5 颗 Support。MATR K1 的 5 个登记 draw 包含 3 组不同 Support。全部方法共享专门化 K0、Bridge、Head 和原有前 100 圈输入。每颗电芯只按真实观测点评分，再取电芯、种子和 draw 的平均。目标 Query 既往已用于评分，本轮是固定队列上的回顾性对照。

## P3 研究方向

容量探索要求 R16 比 R2 在两域的 K3、K5 完整窗中均降低 Query MAE，各种子的平均方向一致，过半不同 Support 集合的配对同向，同时观测到实际能量秩增加及 Support MSE 下降。若容量判据未通过，至少一个域的两个 K 中须各有两种主方法，在至少两个种子上多数不同 Support 集合出现拟合冲突，才优先可靠性。

LoRA 秩阶梯沿用 r8 的源内选定学习率。秩、参数量、优化几何与更新范数可能共变，数值秩更高本身无法解释预测收益。同预算配对可核对表达能力与误差是否同时改善。固定 Query、共享 Support 及有限种子约束了跨队列外推。当前数值核验的置信度高，机制归因和新队列外推的置信度低。
