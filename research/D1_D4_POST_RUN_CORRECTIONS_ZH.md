# 交付核验中的工程与汇总修正

全部80组训练、126000次正式更新和原始预测均按冻结源登记执行。以下修正发生在测试评分后的交付核验，已有预测、权重、训练目标和数据保持原始字节。

1. 报告生成发现环境缺少可选tabulate依赖，改为复用既有n012.report.table，补充极小梯度与大条件数的科学记数显示。未安装新依赖。
2. Torch softplus在输入大于20时采用线性分支，float64 logaddexp保留数学修正项。独立公式核验在6000圈查询出现约1.39e-13的差异，初始2e-14容差过窄。现按anchor×c×smooth×exp(-20)+2e-14的解析上界逐初值校验，结果与界保留于ORACLE_TORCH_NUMERIC_CHECK.json。SOH观测误差和函数拟合目标的定义保持原值。
3. PDF重渲染发现图例与曲线重叠，已移出绘图区，显示oracle分布的全部离群点，并让零范围tau记录显示为点。四类PNG/PDF逐页复核。
4. 原合同要求在GL+rate下配对比较两种形状decoder，初版汇总遗漏这条单独对比。现从原冻结预测补齐spline对physics的配对行。逐项精确核对后，全部原有配对估计与区间数值相同。对比来源于原合同，结果属于同一回顾性分析，保留多重比较限制。

最初预测试评价登记保留为EVALUATION_REGISTRATION_V5.json，当前登记明确标为post-test交付修正，并记录修改后源码哈希。原始失败日志、初版图与配对汇总保存在独立工作存档，失败原因进入ENGINEERING_FAILURES.json。

最终16次profile优化未报告收敛，全部保留终止状态、参数和约束残差。D3多初值优化不保证全局最优。神经网络选定权重的80次正常入口重放最大逐值误差为0，独立检查共83043项通过。
