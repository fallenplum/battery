## 3. D1-L：下一项优先实验——真实局部 Q(V) 形变

此项需要原始/供应逐圈 Q(V) 波形的私有缓存，当前仓库只有汇总 CSV，不能从七项统计量反推出曲线。Codex 在已挂载的源数据上按已有 `scripts/run_d0.py` 的电流资格、窗限、64 点网格重建每电芯前 100 圈：
- HUST：约 5C 充电段 3.1–3.4V；物理循环号来自官方原始记录，容量目标来自原始净容量计数。
- MATR：放电 2.8–3.3V；只认 supplied_cycle_number，预先指定协议上下文。
- Stanford：放电 3.4–4.1V；保留 BEEP 插值标记，形成参数作为已知先验。
- 严禁改动原 D0 的窗口以追求测试集增益；若窗口支持不足须在源训练集独立登记新的窗口实验。

保留 `Q(V)` 64 位置及逐点 valid mask。单圈每个电压段建立同一物理方向的电荷位移，分 8 个**预先固定的等宽电压小段**。每颗电芯从 K10、K50、K100 周围不跨越 100 圈的合格曲线计算稳健锚点，中间缺失不使用未来圈补齐。对于每一小段：
- `drift_10_50`、`drift_50_100`：均值、RMS、有效点比例；
- `persistence`：两段漂移的同向性、窗口内逐圈时间趋势的一致性、噪声尺度；
- `local_vs_global`：去掉该电芯公共形变后的局部残差，防止把整体容量下降冒充局部先兆；
- `geometry`：窗内容量跨度与有据可查的绝对响应尺度单独保存，**不能**用各圈起点归零后声称已保留全局位移；
- 对由原始 5C 充电数据求得的差分/导数，称 `loaded-response derivative proxy`，不可自动写成平衡 ICA/DVA 真实机理。

固定五种匹配对照：
A = 已知先验 + 早期容量；
B = A + 旧七项全局 Q(V)；
C = B + 八小段局部形变（不带时间持续性）；
D = C + 上述 K10/K50/K100 持续性；
E = D + 稳健/受限输出替代线性外推（同数据预算）。

**重点比较 C−B（局部位置）和 D−C（持续性），另比较 E−D（稳健外推）**。每个方案采用相同训练/验证电芯、目标和可用输入预算，模型参数数目、正则化强度和缺失资格的变化需记录。附加局部 bin 顺序扰乱、跨 K 锚点随机顺序作为负对照，不能用随机扰乱后改变有效样本数。

## 4. 训练集/验证集规则

- MATR 200–500：主发展目标，训练 74、验证 20；既有 57 颗测试数据已经打开，只能称既有历史留出。优先在 source 内训练/验证判定局部与时间贡献。
- Stanford 200–500：次发展目标，训练 75、验证 26。对形成参数元组划分做支持诊断，并额外登记组级评价；不得在现有测试 outlier 上调参。
- HUST 200–500 与 500–1000：原始物理轴 sanity/可行性验证，训练 33、验证 11；不预设 HUST 必须带来增益。
- MATR 500–1000 训练 15/验证 5，仅描述性；Stanford 500–1000 训练 37/验证 16，可报告远时距敏感性，不以远期低支持集选超参数。

标准化只在训练电芯拟合。训练内部 3–5 折选择正则强度，source-validation 作为当前开发门控。不读取既有 test 结果进行特征或模型选择；最终只允许独立新外部数据构成真正未暴露验证，或将既有测试明确写成 retrospective holdout。

## 5. 保守门控（不是显著性保证）

- D1-L 的原始窗口有效性不足时，给出每类电芯/片段/小段失败比例，不自动填充值或放宽数据准则。
- C 优于 B 才能说局部位置可能贡献额外预测信息；D 优于 C 才能说早期持续性可能具有额外价值。两条需跨划分/组、逐电芯证据和误差稳定性支撑。
- Stanford 使用预登记的稳健标准化或有界预测头，须在 train/val 选择，不能用测试编号 270 的真值当调参目标；异常样本始终保留。
- 若 D1-L 无增益，先按工况、形成参数、测量口径定位反例，不直接搭建新的 SRSR 模块。
- 一旦获得稳定增益，再开展完全相同的早期信息预算下的 CNN/MLP 局部编码对照、普通融合与 B-only / Δ-only / C-only 的 SSM 路由对照；保留原解析 Flow 不变。随后才研究按未来时距变化的退化速率解码器。
- Knee 只保留算法候选与删失诊断，HUST 不训练伪 EOL 事件。
