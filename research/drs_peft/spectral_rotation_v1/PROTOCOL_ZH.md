# 谱保持条件旋转的源协议筛选

目的是检验前 100 圈放电电学形变能否改善 Support 修正的跨电芯迁移。首轮采用 MATR、Moirai、种子 42、K3。参考模型来自三个已有源折的冻结权重，每折的 Bridge、Head、原 Q/V 源适配和输入协议相同。当前轮次的外层评分使用父实验已登记的源 outer Query 电芯和协议，逐折与原参考拟合、条件映射训练和当前选参协议全隔离。它们属于历史研究中使用过的来源，结论等级为锁定式源域筛选。最终确认仍需要新协议或队列。MATR 最终目标及 HUST 未来标签全程封存。

## 划分与锁定

每折用参考 `fit_ids` 构造 32 个确定性 Support/Query 训练 episode。每个 episode 的 3 颗 Support 与 3 颗训练 Query 独立，分属不同协议。前缀描述的均值与方差只用 `fit_ids`，缺失值在标准化后置零。源内验证使用父实验 inner Query，从对应 Support 池去除 Query 协议后，按不含结果的 UID 哈希选最多 3 个不同的 3 颗组合。源外层每折 20 颗独立 Query，从对应 Support 池去除所有 Query 协议后选 3 个组合。三个外层 Query 集及协议互不重复。每折对元训练、验证、外层分别检查角色和协议。三个折的开发输出和选择均锁定后，才读取用于各折外层评分的标签。选择只使用本折标签。按源数据交叉验证惯例，电芯可在其他折参与训练或验证，本折外层标签封存按该折角色定义。

## 结构与对照

主候选在 12 个现有 Q/V 位置保留旧梯度核心的梯度基 U₀、V，以源合并权重在 U₀ 的正交补构造 U⊥。每层 r=4，电芯特征经有界线性映射产生 4 个角。C 按 episode 零初始化，仅支持损失更新，共 192 个参数。真实特征、常数角和独立训练的打乱条件角使用同一旋转参数化。另固定真实训练与真实 Support 得到的每一层 C，重新随机分配 Query 和锚的早期描述，形成严格逐层同谱反事实。错配在相同角色内确定性去固定点，描述边际分布保持。

描述在 2.8–3.1 V 共同实测坐标提取。全局容量项、电压导数项、8 段残差和 8 段实测 Q(V) 变化各产生有符号尾段水平、早晚差和真实循环坐标趋势，共 54 维。容量量除以铭牌 Ah。参考输入保留原 early SOH 锚点。数据缓存没有独立的完整实测 early SOH 序列。Q(V) 描述不绑定具体电化学失效机制。

旧静态核心沿相同的原梯度空间。DRS 用同一形变描述调制固定空间的行列系数。单侧增益对照 GAIN 使用相同条件网络规模和同一形变信息，空间固定。固定联合 2r 空间 JOINT2R 使用左右维度 8×2 的核心，适配预算同为 192，左空间完整，右空间和最高秩相应受限。K0 为未适配的同一参考。CAL2 沿用两参数定义及 Support-Gram ridge，保留历史 K3 组合，验证选择九个 ridge/收缩组合。小步 LoRA-r8 同一 Q/V、MSE 和采样，源内选择 1e-6、1e-5、3e-5 和 1、10 步组合。LoRA 更新参数量独立披露。

常数角直接学习各层四个 bias。输入置零保留映射参数容器，避免对多个重复常量权重执行 Adam 导致角度步长放大。初次工程运行在该对照训练前停止。这次修正先于正式开发和任何本折外层评分。

角度与增益映射用真实非线性路径训练。每个源训练 episode 中通过等电芯采样 MSE 的三步可微 Support SGD 更新 C，再以训练 Query 的等电芯采样 MSE 训练映射，保留路径 C(ψ) 的梯度。各方法的适配目标均为等电芯采样 MSE，观察点等间距选取、每电芯至多 512。映射输出的最终状态固定，验证选三档核心步长的全窗 MAE，等分取较小步长。外层评分使用全部有效观测。主条件角的上限为 π/6。其优势是在给定 C 时角度保留全部非零奇异值。其适用限制包括固定 8 维联合空间、跨协议观测偏移和输入依赖推理开销。

## 评分与停止

按电芯汇报 101–5000 全轨迹和 101–200、201–500、501–1000、1001–5000 分窗。主 MAE 在每电芯内平均各抽样，再对物理电芯等权，记录每折方向、观测覆盖、负迁移率、Support 误差和实际时耗。参数对照在固定 8 颗源拟合锚点上把核心缩小到两臂共同的较低实际更新 Frobenius RMS，重新跑非线性前向。真实模型预测同时在相同源锚点、无标签 101–5000 固定网格测 RMS，另做配对输出等扰动分析。参数、输出等幅是两种独立诊断，均不以外层标签选择系数。

放行要求真实条件旋转相对 K0、CAL2、小步 LoRA、旧静态、DRS、GAIN、固定联合、常数角、两种置乱的全窗 MAE 绝对均值至少低 1e-5，至少两个源折同向。参数范数对齐后，相对常数角与独立训练的置乱仍需均值同向且至少两个源折同向。实际源锚 RMS 在所有任务均不超过 1e-5 记录为近零更新。任一必要对照未过则保留对应阴性或不足结论，停止扩大 K、条件网络或主干，当前筛选不依据外层分数改参。无新目标域拟合。正结果仍需独立未暴露的确认队列。
