# 真实预测修正的方向、幅度与迁移诊断

父版本为 `0bfa14b40ff3658d3a2027923d7c697f3d1ebf92`。沿用源专门化 Moirai、合法前 100 圈、固定 Bridge 和 Head、12 个 Q/V 位置、每颗电芯至多 512 个确定性训练观测点。目标 MATR 和 HUST 仍为冻结总 K 及已暴露的固定 Query。

## E1 输出误差分解

令 e=f0−y、d=fadapt−f0。逐电芯对真实观测时点计算 e·d 与 d²，再按电芯等权。计算 2η〈e,d〉+η²〈d,d〉，逐项与 f0+ηd 的直接 MSE 差核对。输出 MAE、MSE、真实修正 RMS、精确符号、分窗计数和正向约束 oracle η。η=1 对应实际非线性模型输出。所有 oracle 都依赖已观测标签，仅用于回顾性诊断。

首轮源域使用三个原协议折、种子 42、每折所有单 Support 候选及 K3/K5 登记 draw0，运行 ABBA(4,4) 与 LoRA-r8。原源任务仅保存标量选参结果，本轮按锁定学习率与 30 步恢复真实预测。源内 Support 和 Query 与该折冻结参考的拟合集分离。

源方向诊断完成后，目标 Query 读取旧预测，目标 Support 加载已保存适配状态前向重放。采样观测视图沿用训练时的 padded cycle grid 和观测掩码，完整观测视图按 101–5000 实际观测掩码评分。目标段优化为零。保留 540 个登记非零槽及 504 个独立状态口径。无观测窗口保留空值。

## E2 源域优化尺度

仅比较 ABBA(4,4) 与 LoRA-r8。三折、种子 42、K1/K3/K5 的原 draw0，预定学习率 1e-5、3e-5、1e-4、1e-3。统一 60 步轨迹，记录 10、30、60 步镜像。记录原输出的 Support MSE、源 Query MAE/MSE、权重更新谱、范数、实际训练耗时和显存。每折固定拟合源锚点，在不读其未来标签的情况下计算函数扰动 RMS。对相同折、K、学习率、步数的两组使用两者较小的锚点扰动半径构造输出尺度对照。该对照仍包含修正方向差异。

## E3 源协议留出评价

读 E1 单电芯 Support 产生的真实修正。按冻结参考的 fold 在源内做 Query 协议组留一，训练移除与留出组相同协议的 Support 以及同一物理 Query。用前缀电流、电压范围、容量响应、局部电压形态和 frozen encode 距离等观测量。协议 ID 仅用于留出、审计和分层。时距作为显式属性。未来观测及符号参与打分和训练标签。概率与判决只评价已观测的源协议组，记录每折、每协议与电芯覆盖。

第一项优势为方向与尺度的代数可判别性。第二项优势为使用实际输出的共享扰动尺度。第三项优势为按协议留出评估可观测预测信息。主要风险包括小样本和重复电芯、参考模型跨折差异、源锚点半径在其他 Query 上的分布偏移，以及固定目标队列的历史暴露。
