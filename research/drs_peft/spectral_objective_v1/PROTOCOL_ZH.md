# 条件旋转的 Query 目标与适配步长对齐

本轮检验条件旋转在三步 Support MSE 适配后，使用 Query MAE 学习映射并对齐内循环步长，能否改善跨工况预测。起点为提交 `87ad1c8c403503f15833f825be91c748bbf3a7bd`。既有结构的完整轨迹 MAE 为 0.030985147，K0 为 0.029134282，小步 LoRA 为 0.029175463。前轮核心臂的选择集中在步长网格下界 0.1，源元训练内循环使用 0.5。本轮复试沿用原算子，历史停机判定 `STOP_SIMPLE_BASELINE` 保留。 [前轮报告](../../../report/drs_peft/spectral_rotation_v1/FINAL_REVIEW_ZH.md)

## 数据与角色

- MATR 源域共三个折。每折参考主干、Bridge、Head、Q/V 源专门化权重和 12 个映射位置均使用原 reference seed 42 的冻结状态。
- 评价 plan seed 为 42。直接继承 v1 登记中的 fit 名册、内验证和外层的电芯与 Support 组合、8 颗拟合锚点及 seed42 的 32 个训练 episode。评价角色内置乱沿用原盐并显式登记 donor UID 序列。
- 每折内验证 8 颗 Query，Support 组合数为 3、1、3。每折外层 20 颗 Query 和 3 个组合。三个外层共 60 颗不同 Query、39 个不同工况。
- 同折拟合、验证、外层按工况隔离。所有 episode 的 Support 和 Query 工况互斥。不同折之间存在角色复用，外层人群有历史曝光。本轮证据等级为源域开发筛选。
- Seed43、44 分别从各自折的拟合名册生成 32 个不同训练 episode。每个 episode 有 3 颗 Support 和 3 颗 meta Query，其物理电芯及工况全互斥。每种子的所有目标、方法与步长共享该计划。评价名册、锚点和置乱 donor 对所有重复保持一致。
- 使用已有 54 维有符号放电描述，仅用原始前 100 圈。各折标准化统计来自本折拟合名册。内外训练每颗电芯至多采样 512 个有效观测。验证和外层评价使用 101–5000 圈内的全部实测点。

登记、开发和筛选均使用同一份 [冻结配置](../../../configs/drs_peft/spectral_objective_v1/CONFIG.json)。登记阶段只核对元数据、前序计划和参考 SHA-256。外层评分由开发锁授权，MATR 最终目标和 HUST 无新未来标签访问。

## 更新和目标

在原双基底和角度上界 \(\pi/6\) 下，每层保留同一 \(4\times4\) 核心。每个 episode 的核心从零开始，进行三步等电芯 MSE 更新，并采用原梯度裁剪。适配核心总参数量为 192。真实旋转和 GAIN 的 mapper 各 2,640 个参数。常数角保持零描述输入和原有效参数口径。

每个训练臂从全零 mapper 和全新 Adam 状态开始。Adam 步长为 0.01。MM 的外层目标为 Query MSE，MA 为精确 Query MAE。二者都保留 Support 更新到 mapper 的完整微分链。每个训练臂的内循环、验证、锁定适配均使用同一正步长 \(\alpha\)。固定核心时的谱保持限于参数增量。

## Stage A 源开发筛选

Seed42 在四个 mapper 臂、两个外层目标、四档核心步长和三个折上训练 96 个 mapper。四个臂为真实旋转、常数角、独立训练置乱和 GAIN。训练和验证同时覆盖 \(\alpha\in\{10^{-4},10^{-3},10^{-2},10^{-1}\}\)。独立置乱仅在相同角色内交换描述。

| 基线 | 本折源内验证网格 |
| --- | --- |
| K0 | 冻结参考直接预测 |
| STATIC_CORE | 上述四档核心步长，每次三步 |
| LORA_SMALL | rank 8，学习率 \(10^{-7},10^{-6},10^{-5},3\times10^{-5}\)，步数 1、10 |
| CAL2 | 岭系数 \(10^{-4},10^{-2},1\)，缩放系数 0.01、0.1、0.25、1 |

所有网格点保留。各折使用其完整观测验证 MAE 分别选择每个方法和外层目标的配置，严格同分优先较小核心步长。若 `ROTATION_TRUE_MA` 在不足两个折的验证 MAE 至少优于同折 K0 \(10^{-5}\)，登记 `STOP_NO_VALIDATION_SIGNAL`，Stage B 和 C 记为 `NOT_RUN_BY_STAGE_A_GATE`。

源内筛选可以在限额内检验工程信号。每折只有 8 颗验证电芯，折 1 只有一个 Support 组合。阈值用于运转筛选，外推到独立队列仍需确认。

## Stage B 锁定后的元训练重复

Stage A 通过后逐折锁定所有超参数。Seed43、44 各以拟合角色训练 24 个 mapper。真实旋转再以已选 TRUE_MA 步长训练同计划、同初始化的 MM 对照。Seed42 使用已有网格状态。如果同种子的 MM 配置正好匹配该步长，沿用同一状态。

最多训练 150 个 mapper，含 4,800 次 Adam 更新与 14,400 次可微 Support SGD 更新。各折参考模型继续来自 seed42。LoRA 的随机初始化按训练重复种子改变。同 seed 的各学习率共享初始化。K0、CAL2 和 STATIC 的确定性预测按需复用，收据记录真实预测哈希及复用状态。

## Stage C 开发锁后评分

重新检查三个折的配置、选择和状态哈希，再读取该折登记的源外层角色。主指标先在电芯内对实测点求 MAE，然后平均三个 Support draw 和三个训练 seed，最后对 60 颗电芯等权。每个 seed、折、协议和电芯保留配对差值。39 个协议等权 MAE、受损电芯数及最差受损协议和电芯为补充结果。

四个固定时距窗分别报告可观测电芯的宏平均及对完整轨迹的贡献。贡献按每颗电芯各窗观测数占自身完整窗观测数的权重计算，无观测窗贡献计零。逐电芯和宏平均应分别闭合。若采用协议块重采样，只描述当前固定队列的变化，按折保留 20/60 权重并保存抽样索引。

同核心反事实仅替换 Query 和锚的早期描述，保持真实 Support 及该次核心。独立训练置乱另行评价。TRUE_MA 与常数角及独立置乱均以较小锚点参数更新 Frobenius RMS 为共同幅度，缩放核心后非线性重放。固定预测方向的输出收缩采用锚点输出 RMS，作为单独诊断。

## 预定判定及交付

- TRUE_MA 相对 K0、小步 LoRA、CAL2、STATIC、GAIN_MA、CONST_MA 和 SHUFFLED_MA 均须达到至少 \(10^{-5}\) 的完整轨迹平均改善、至少两个折同向及三个训练重复全部同向。
- 参数等幅的常数角与独立置乱对照、同核心 Query 置乱对照均要求总体及至少两个折同向。锚点近零和 Query 近零分别按实际扰动披露。
- 目标归因还需 TRUE_MA 相对同 \(\alpha\) 的 TRUE_MM 的平均差值为负，并在至少两折及全部训练重复同向。MM 和 MA 的全网格、验证边界和方向反例全部保留。
- 通过完整门槛只得到 `ELIGIBLE_FOR_SEPARATE_SOURCE_CONFIRMATION`。各失败门槛独立登记。Stage A 早停时保存真实验证、轨迹与成本，后续材料以未运行状态记录。
- 预测和状态包留在 runtime，公开收据绑定 SHA-256。独立复核依据封存的状态与逐电芯预测重算已执行阶段。当前轮证据应用于固定参考和固定源队列。
