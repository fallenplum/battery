# Moirai 的 ABBA 少样本复现合同

## P0 与 P1

以既有源专门化 Moirai 为共同参考。将 12 个冻结源核心折叠进对应线性层的权重，再接入 ABBA、LoRA、HiRA 和 AdaLoRA。Bridge、Decoder 和其余主干权重均冻结。先验证零增量重放、上游算子与实际 Moirai 的梯度和合并输出。

主矩阵为 ABBA(4,4)、LoRA rank 8、HiRA rank 8、AdaLoRA 平均 rank 12 到 rank 8。前三组每层具有相同可训练参数量。AdaLoRA 分别计量初始化张量预算、最终分配和实际生效秩。ABBA 总秩预算 8 时理论秩上界为 16。LoRA rank 2 与 rank 16 只用于容量对照，固定使用 rank 8 在对应 K 的源内选择。

原版算子使用作者代码和论文约定。实验中的秩、学习率、短步数调度及目标任务为电池移植设置。ABBA 的论文 α 为 2，对应作者实现两支 alpha 值均为 1，整体缩放为 1。HiRA 保留作者仓库的单位缩放。LoRA 使用 α/r=1。AdaLoRA 使用官方秩分配和正交约束。

源内以三个协议折、种子 42、五次登记抽样和两个学习率进行选择。每个方法与 K 依完整观测轨迹的平均电芯 MAE 选择。目标两域共用该选择。MATR 和 HUST 保留原全域总 K=0/1/3/5、三个目标种子与五次登记抽样。所有方法共享固定 Query，与各自当前 K 颗 Support 分离。主预测为固定 101–5000 圈的真实非线性前向。Query 后缀仅在完整预测锁后读取。目标固定池已有历史暴露。

## P2 与 P3

逐模块计算相对冻结参考的实际更新奇异谱、Frobenius 范数、数值秩、稳定秩、熵秩和 99% 能量秩。记录 Support MSE、Query MAE 和负迁移，并报告完整观测及各时距的有效样本数。

容量证据先看 LoRA rank 16 对 rank 2 在共同优化步数下的配对方向，辅以 rank 8 邻级和同预算四种方法。不同参数化同时改变可达子空间、更新尺度和优化轨迹，观察差异仅对当前矩阵成立。若容量对照缺乏一致收益而支持集改善与 Query 失效反复共现，研究判断优先指向可靠性约束。正式选择之后保留负结果与个体反例。
