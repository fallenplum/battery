## 3. D3：Decoder的Oracle函数表达能力（**诊断，不是主任务成绩**）

### 3.1 核心科学问题

对每颗真实电芯，**允许使用其完整实际观测未来SOH**，只优化Decoder自身的个体参数，衡量该函数族对这条已知轨迹的最小可能逼近误差：

\[
\epsilon_{i,\mathcal F}^{oracle}=\min_{\theta_i\in\Theta_{\mathcal F}}\frac{1}{|\mathcal T_i|}\sum_{t\in\mathcal T_i}\left|f_{\mathcal F}(t;\theta_i,SOH_{100,i})-SOH_i(t)\right|.
\]

**含义**：这是带未来标签的事后拟合；无法作为早期预测成绩。仅说明函数族是否具备表达观测曲线的能力。如果oracle误差很大，可能是函数族、数值优化或观测非单调性的限制；如oracle很小但早期模型误差很大，必须再查参数映射、数据可辨识性和优化。

### 3.2 函数对照与公平性

- D3-A：N012原始 `PhysicsBasis`（对数+线性+Softplus激活）的**相同物理参数边界、同SOH100锚点**。
- D3-B：`MonotoneSpline`（现行10段非负速率），相同真实查询与锚点；同时记录参数个数。
- D3-C：非负自由速率的**低复杂度、明确参数化**参照（禁止为每个观测点单独引入一个自由参数冒充公平对照）。可用有限结点的非负速率样条；注明其自由度。
- D3-D：非单调的有限维平滑样条/低阶多项式，仅作为数据存在测量回升时的**表示能力参照**，不可当合法物理趋势。
- D3-E：锚点固定的常数退化速率/单线性累积退化最简基线，说明低复杂度下界。

对于原`PhysicsBasis`有跨电芯共享的`time_c`与`smooth`，必须分别提供：（i）共享c,w在折内训练电芯上学习、应用于其他电芯的诊断模式；（ii）c,w也允许逐电芯自由拟合的**更宽松oracle上界**。后者不可和实际网络公平比较，必须显式标注oracle额外自由度。

### 3.3 数值与误差诊断

- 每颗电芯至少8个不同随机/确定性初值，多次拟合保存收敛状态、初始值、最终loss、函数值与参数边界；使用float64或双精度数值核验，必要时对照SciPy最小化。
- 使用真实观测mask，按单颗电芯平均MAE；分别报告101–200、201–500、501–1000、1001+窗口的有效电芯数，并报告EOL前/后与是否有SOH测量回升的诊断。
- 结果按训练/验证/测试UID分组单列；外层test的oracle结果只能在所有预测型实验和结构选项冻结之后出具，仅用于事后解释。
- 可额外进行 `FUTURE_PREFIX_DIAGNOSTIC`：使用实际第101–500圈标签估计参数，再在501+的**可观察**部分预测。这仍使用了K100之外的未来信息，不准作为合法K100预测或和M1主表并列。
- 对每个函数族输出分位数误差、fit_gap=`legal_K100_MAE - oracle_fullfit_MAE`；说明这个差值包含函数/预测/优化/目标差异，不是严格的纯“信息可辨识下界”。
- 对`PhysicsBasis`在固定早期查询网格计算加速项占总累计损失的比例、tau在实际监督时距内的有效比例，分析是否激活分量根本得不到梯度；不能依据test诊断自行更改参数函数族。

**D3必须作出的判断**：①oracle本身高误差→表达/观测形状问题；②oracle小误差但前缀推断高误差→重点检查可预测性或训练；③多组参数都能同样拟合→识别病态，不能宣称真实机制参数已被识别。

## 4. D1：显式早期物理特征的信息增量（合法K100预测）

### 4.1 保留的模型框架

继续使用 `n012.EarlyEncoder` 的**独立架构**，不导入旧M1的神经网络类，不重新堆叠Mamba/Flow。复用N1在各个外折使用**内部validation**预先选定的encoder结构（若完整矩阵需统一固定architecture另设单独注册，不依据test选择）。固定decoder=`query_mlp`，loss=现行masked per-cell suffix MAE，seed42、训练预算150 epochs、batch8、AdamW lr3e-4、weight_decay0.01、gradient clip1.0，选权由该折validation首个最优epoch决定。对已有`N1:nested`及对应各折`query_mlp`原始预测按UID完全复用为D1基准，不重训基准除非审计发现定义不符。

### 4.2 四组必跑特征消融

| 臂 | 原始VIQ/ΔQ、cycle、policy、SOH100 | 新增global G20 | 新增local（64点残差+8×26窗统计） | 作用 |
|---|---|---|---|---|
| D1-0 | ✓ | — | — | 复用N1基准 |
| D1-G | ✓ | ✓ | — | 全局退化响应增量 |
| D1-L | ✓ | — | ✓ | 局部退化响应增量 |
| D1-GL | ✓ | ✓ | ✓ | 全局局部协同增量 |

- global/local 必须使用仓库已认证早期物理特征与对应mask，显式汇报其对应量不是LLI/LAM等电极分辨真值。
- 物理特征支路首版采用轻量的 masked MLP / 1D pooling + Linear，融合方式仅一处 `concat + projection` 或 residual-add（在注册时冻结一个，另一个作为次级开发控制）；不要拿旧 `PhysicalResponseEncoder` 类直接装入新网络。
- 保留原主干输入、残差与mask；所有正常模型都用同一早期SOH锚点。记录`extra_params`并加入宽度/参数量对照：至少一个`D1-0-capmatch`使用无新特征但近似相同参数数，避免仅因参数增加误判特征有效。
- 如果新增特征造成无效点不同，采用union/intersection mask必须提前明确；不允许仅筛选特征完整的电芯而改变队列支持与训练/测试分母。
- 对 `ΔQ(V)` 和原历史M1`reference_viq`的信息差异作数据可恢复性审计：新模型拥有ΔQ通道不等于必然拥有历史M1的完整reference V/I/Q信息。此项列入`UNMATCHED_INFORMATION.md`，不得声称D1-GL已与M1“完全信息预算对齐”。
- D1结果在MATR/HUST分别报告，HUST没有历史M1成绩，不能凭空补写；各域仍为单域训练。

### 4.3 D1的严格结论

只有D1-G/L/GL相对**同Encoder+同Decoder+同loss+同划分** 的D1-0取得稳健增益，才支持“显式物理响应特征提供有效增量信息”。即使它优于D1-0，也不能宣称数据可以识别真实SEI/LLI/LAM机制。若只优于未参数量匹配臂，结论应降级。

## 5. D2：训练目标（速率辅助监督）的因果控制

### 5.1 与历史M1精确核对

从 `scripts/unified_matr/train_seed42.py` 读取冻结 `rate_targets/rate_mask`；历史使用窗口 `[200,500]`、`[500,1000]`，率乘以1000作数值尺度，辅助权重0.1。正确含义：仅有两个真实端点的电芯可以提供该段速率标签；未支持的rate target必须掩码，不可补值。HUST若没有完全同定义的认证速率标签，**只从训练端点（200、500、1000）真实观测且经审核有效时**构造同口径标签并保存原始观测来源和mask；如无法资格认证，明确阻断HUST辅助速率臂，仍可做MATR。

速率：`r200_500=(SOH(200)-SOH(500))/300`，`r500_1000=(SOH(500)-SOH(1000))/500`。预测速率从预测完整轨迹相同cycle端点求得。损失仅对有支持的电芯/窗口平均：

`L = L_trajectory + lambda_rate * 1000 * mean_supported_cell(mean_supported_window(|rhat-r|))`。

首版 `lambda_rate=0.1`（完全模仿历史M1口径）；如该值存在train/val不稳定，在冻结的开发方案中仅允许从预先写定的小网格（0.0, 0.03, 0.1）**利用每外折内部validation**挑选；不得用test调整。选择发生在test评分前。必须保存每窗口有支持电芯数、该项loss幅度、各epoch有效梯度及是否与主loss冲突。

### 5.2 要跑的2×2正交对照

使用相同折内Encoder+`query_mlp`，D1-GL作为物理特征臂，比较：

| Arm | 早期物理特征 | 速率辅助监督 |
|---|---|---|
| F0L0 | 无（复用N1） | 无（复用N1） |
| F1L0 | 有（复用D1-GL） | 无 |
| F0L1 | 无 | 有 |
| F1L1 | 有 | 有 |

每域每外折只增加`F0L1`与`F1L1`所需训练，复用已冻结臂。计算一阶特征效果、一阶loss效果与交互项（difference in differences），避免把两者改善混为一个贡献。**其它网络、初始化策略、训练轮数、query以及验证准则都固定。** 若已有新臂在构造上参数不匹配，记录并做额外容量控制。

建议附加一个小规模`monotone_spline`/`physics_basis`在F1L1条件下的配对受控对照（每域开发折优先；通过合法val冻结后扩展全五折），但不能在看到测试表现后偷偷扩张模型搜索范围。目标是确认Encoder+Loss修正是否改变Decoder优劣。

### 5.3 额外必要诊断

对MATR重点检查中后期预测**有符号偏差**：501–1000历史N2 physics_basis≈+0.0573。评价N2+物理特征/辅助loss后，bias是否减少，而不是只看全轨迹MAE。

## 6. D4：动力学参数的可辨识性、早期预测性与优化状态

D4必须拆成两个维度：**结构参数辨识的稳定性** 与 **K100前缀预测能力**，两者不同。

### 6.1 D4-A：函数参数稳定性（oracle诊断）

- 复用D3每电芯多初值`PhysicsBasis`拟合，记录`a,b,c,tau`（注意代码里`c`是加速幅度，`time_c`才是对数时间尺度，严禁符号混用）、跨初值分散、不同参数组合对应的轨迹MAE。
- 对tau、加速幅度和前中期有效速率做profile loss或带约束的小网格敏感性曲线；报告同等拟合质量的参数集是否很宽。预设“近似等价拟合”门槛，例如相对最优拟合MAE≤5%且绝对差≤0.002的交集（如果太严格导致无支持，报告支持人数并做阈值敏感性，不可暗改主门槛）。
- 核对可观测的标签区间支持。若某电芯最长仅600圈，不能据此宣称已识别1000圈后的tau。对长随访组与短随访组分层报告参数不稳定性。
- 可计算局部Jacobian `J_{t,j}=∂ŷ(t;θ)/∂θ_j` 的奇异值、条件数与近零方向，但应按真实支持点和尺度归一化；共享参数/个体参数要分别处理。参数相关、高条件数只支持**当前模型下局部辨识病态**，并不证明电池内部物理机制不可辨识。

### 6.2 D4-B：前100圈能否预测真实未来动力学？

首先使用**直接定义、可观测支持**的未来量作为监督代理，而不是把oracle拟合出的`tau`当作真实物理标签：

- 200–500平均SOH衰减率；
- 500–1000平均衰减率（仅精确端点支持电芯）；
- 已有实际SOH序列可计算的其他预先定义窗口量，记录相应有效数量；
- 未来EOL80仅MATR真实事件支持，HUST必须按右删失处理，不直接拿终止点作EOL。

使用相同物理电芯划分，比较：

1. Early SOH100 +已知policy的Ridge/GBR等小模型；
2. +原始VIQ/ΔQ的预先固定低维统计；
3. +G20物理特征；
4. +Local物理特征；
5. +G20+Local；
6. （非独立方法）D1/D2已冻结Encoder输出`z`作为特征，仅在合法训练分折内拟合轻量参数预测头。

**必须使用outer-train内cross-fitting或严格训练/验证分离**训练目标代理与特征选择，不能给训练电芯输入未来信息；outer-test未来标签只用于最终评分。对200–500和500–1000两个目标分别报告n、MAE/RMSE、R2与policy-only增益；若训练样本量少，正则化优先、不引入更复杂模型。对于真实长期参数`tau`等，只能用D3产生的oracle拟合参数做附属、低信任的分析，并且先审计多初值解是否稳定、样本是否实际覆盖其激活区间。

必须区分 **未获得增量证据** 与 **证明没有可预测信息**；不得根据统计不显著就断言真实世界不可预测。也不能把多条由同一电芯生成的未来观测点当作独立训练样本。

### 6.3 D4-C：训练梯度及激活门诊断

真实神经网络在**训练电芯**上做最小干预的前向/反向审计：

- `raw[:,0:4]`、`a,b,c,tau`、`time_c,smooth`，在每个epoch、不同fold的直方图/分位数；
- `∂L/∂raw_j`或对应head权重的梯度范数，分别对应三分量与tau；
- `tau`映射的物理循环位置 `100+1000*tau` 与该电芯**实际最长观测循环**的比较；
- 加速分量在各时距 `101–200 / 201–500 / 501–1000 / 1001+` 的累计退化贡献比例；
- 如最佳checkpoint早于12轮，对比第1轮与最终轮梯度分布、training vs validation曲线，判断是否优化失败或验证不稳定。

特别注意当前源码 `tau=4*sigmoid(raw_tau)`；初始化网络输出约0时对应tau≈2，即绝对循环约2100圈；`smooth=softplus(-1.5)+0.03≈0.23`。这可能造成有监督区间内的加速项梯度很弱，**只是一条待检验的优化解释**。

允许仅在train/val开发设置下对原PhysicsBasis的**固定预注册初值**进行有限控制（例如把初始tau设为u=0.5、1.0、2.0三档，保持函数族/参数量不变；训练结束前冻结候选集合）。必须报告该变化是否影响train/val梯度和初始损失；严禁观察test后挑“最优初始化”展示主结果。

## 8. 完成判据与决策树（不可按测试分数临时改写）

A. **D3 oracle拟合差**：优先研究函数族及观测趋势/残差；不应靠换更大Encoder解决结构错误。

B. **D3拟合好、D1显著获益**：早期物理表征问题得到支持；再判断D2是否进一步改善，考虑新独立Encoder适配而不是回退SR-111。

C. **D3拟合好、D1不显著，但D2有效**：训练目标/速率监督比特征预算更关键；讨论偏差-方差与训练信号不足。

D. **D3拟合好，D1+D2仍不行，D4显示关键参数不可稳定预测**：把“可辨识性受限的个体动力学预测”作为新研究问题，先尝试**少量参数共享/先验收缩**，不允许直接加入复杂MoE/概率生成作为性能补丁。

E. **D3拟合好、D4可预测，但网络梯度不足**：针对参数化/初始化/损失进行最小优化控制，不必弃用物理Insight。

F. **D1/D2/D4存在混合结论**：保留所有负例，对每个证据链做限制性结论，禁止为了“出论文”夸大显著性或强行解释真实电化学机制。
